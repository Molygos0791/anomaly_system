# 异常检测算法说明

## 1. 3-Sigma 准则（统计法）

**原理**：对于近似正态分布的信号，约 99.7% 的样本落在 [μ−3σ, μ+3σ] 区间内。落在此外的点判为异常。

**判定**：`|x − μ| / σ > k`（默认 k=3）

**优点**：实现极简，速度快
**缺点**：假设正态分布；均值/方差对异常本身敏感（污染问题）

---

## 2. IQR（四分位距）法

**原理**：基于中位数的位置统计量，抗偏态。

**判定**：`x < Q1 − k·IQR`  或  `x > Q3 + k·IQR`（默认 k=1.5）

其中 IQR = Q3 − Q1

**优点**：对偏态分布友好
**缺点**：仅适合一维点级异常

---

## 3. MAD（中位数绝对偏差）

**原理**：用中位数和 MAD 替代均值和 σ，避免被异常值污染。

```
median = median(x)
MAD = median(|x − median|)
score = 0.6745 × |x − median| / MAD
```

判定：`score > k`（默认 k=3.5）。系数 0.6745 让 MAD 在正态下与 σ 一致。

**优点**：极强鲁棒性（即使 50% 异常也不影响）
**缺点**：仅一维

---

## 4. Isolation Forest（孤立森林）

**原理**：构建随机二叉树，异常点更容易被早期分离 → 路径越短越异常。

**关键参数**：
- `contamination`：预估异常比例（默认 5%）
- `n_estimators`：树数（默认 100）

**优点**：无监督、高效、适合高维
**缺点**：对参数敏感；对线性流形分布不友好

---

## 5. LOF（Local Outlier Factor）

**原理**：比较样本与其 k 近邻的局部密度比值。密度显著低于邻居 → 异常。

**关键参数**：
- `n_neighbors`：邻居数（默认 20）
- `contamination`：异常比例

**优点**：检测局部异常（簇内低密度点）
**缺点**：O(n²) 距离计算，大数据慢

---

## 滑窗特征工程

工业振动/电流等信号的异常常表现为**统计特征突变**而非单点偏离。本系统支持将原始时序转换为 6 维特征：

| 特征 | 公式 | 物理意义 |
|------|------|---------|
| mean | 窗口均值 | 信号偏置 |
| std | 窗口标准差 | 波动程度 |
| rms | √(mean(x²)) | 能量 |
| peak-to-peak | max − min | 振幅范围 |
| kurtosis | 四阶矩 | 冲击性 |
| skewness | 三阶矩 | 不对称性 |

`IsolationForest` 与 `LOF` 可在特征空间运行（`use_features=True`），效果通常优于点级。

---

## 评估指标

合成数据带 ground truth 标签，可计算：

| 指标 | 公式 | 说明 |
|------|------|------|
| Precision | TP / (TP + FP) | 报警准确率 |
| Recall | TP / (TP + FN) | 异常召回率 |
| F1 | 2PR / (P + R) | 平衡指标 |
| ROC-AUC | ROC 曲线下面积 | 阈值无关排序能力 |
| PR-AUC | PR 曲线下面积 | 极不平衡场景更可靠 |

工业场景通常 **Recall > Precision**：宁可多报，不可漏检。

---

## 算法选型建议

| 场景 | 推荐 |
|------|------|
| 简单点级异常 + 正态分布 | 3-Sigma |
| 噪声大 / 偏态分布 | MAD 或 IQR |
| 高维特征 / 大数据 | Isolation Forest |
| 局部模式异常 | LOF |
| 工业振动信号 | IForest + 滑窗特征 |

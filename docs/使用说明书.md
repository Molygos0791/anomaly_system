# 使用说明书

## 工业时序数据异常检测系统

> 适用版本：v1.0 (MVP)

---

## 1. 安装与环境

### 1.1 系统要求

- 操作系统：macOS / Linux / Windows
- Python：3.10 或更高版本
- 内存：建议 ≥ 4 GB
- 浏览器：Chrome / Edge / Safari

### 1.2 依赖安装

打开终端，进入项目目录：

```bash
cd anomaly_system
```

**第一步：创建并激活虚拟环境**

```bash
# macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

**第二步：安装依赖**

```bash
pip install -r requirements.txt
```

依赖列表（共 10 个核心包）：

```
nptdms          # TDMS 文件解析
numpy / pandas  # 数值计算
scipy           # 统计函数
scikit-learn    # 机器学习算法
sqlalchemy      # ORM
streamlit       # Web 界面
plotly          # 交互图表
pytest          # 测试框架
pytest-cov      # 测试覆盖率
```

### 1.3 启动应用

```bash
streamlit run app.py
```

启动后浏览器自动打开 `http://localhost:8501`。如未自动打开，手动访问该地址即可。

如要后台运行：

```bash
nohup streamlit run app.py --server.headless true > /tmp/streamlit.log 2>&1 &
```

停止：

```bash
pkill -f "streamlit run"
```

## 3. 完整使用流程

### 步骤 1：导入数据

进入 **🗄️ 数据管理**，切到「📥 数据导入」标签，三种方式任选：

#### 方式 A：一键生成示例数据（最简单）

点击 「🎲 生成 + 导入示例数据」按钮：

- 自动生成 3 个通道（vibration / temperature / current）
- 每通道 5000 个点，含 100 个人为注入的异常
- 几秒内完成

**适用：** 首次试用、教学演示

#### 方式 B：扫描本地 TDMS 文件

如果你已把 `.tdms` 文件放进 `data/` 目录：

1. 在「方式 2：扫描 data/ 目录」下拉框选择文件
2. 系统自动显示通道元数据（**通道名 / 点数 / 采样率 / 单位**）
3. 配置导入参数：
   - **每通道最多读取点数**：0 = 全部，建议 200000（避免大文件入库慢）
   - **降采样步长**：每 N 个点取 1 个，建议 10
4. 查看「预计入库点数」估算
5. 点击「📥 导入此本地文件」

**适用：** 已有真实生产数据

#### 方式 C：浏览器上传 TDMS

「方式 3：上传 TDMS 文件」：

- 拖拽或点击上传 `.tdms` 文件
- 上传后流程同方式 B（自动显示元数据 + 配置降采样）

**适用：** 临时分析的小文件

#### 关于降采样的建议

| 文件大小 | 总点数 | 推荐参数 |
|---------|--------|---------|
| < 10 MB | < 10 万 | 全部导入（max=0, ds=1）|
| 10-100 MB | 100万-1000万 | max=500000, ds=5 |
| 100 MB-1 GB | 1000万+ | max=200000, ds=10 |
| > 1 GB | 千万级 | max=100000, ds=20 |

> **原理：** SQLite 单点入库的瓶颈在 IO 而非 CPU。降采样后既能保留信号特征，又能让 UI 流畅。

---

### 步骤 2：批量检测

进入 **🔍 批量检测**：

1. **选择设备**：下拉选择已导入的设备
2. **选择通道**：选目标通道
3. **选择算法**：5 种可选
   - `3-Sigma (统计)` —— 简单快速，适合正态信号
   - `IQR (统计)` —— 适合偏态分布
   - `MAD (鲁棒统计)` —— 噪声大时更稳
   - `Isolation Forest (机器学习)` —— **推荐工业振动信号**
   - `LOF (机器学习)` —— 局部异常
4. **调整参数**（展开「⚙️ 参数」）：
   - 统计法：`k` 值（默认 3.0）
   - ML 法：`contamination`（异常比例预估，默认 0.05）+ 可选「使用滑窗特征」
5. 点击 「🚀 开始检测」

**结果包含**：

- ✅ 检测统计（异常数 / 异常率）
- 📊 信号曲线 + 异常红点叠加
- 📉 异常分曲线（橙色，越高越异常）
- 🚨 异常率 > 1% 时**自动生成告警**
- 📜 该通道的「检测运行历史」表

---

### 步骤 3：实时监控（流式仿真）

进入 **📊 实时监控**：

1. 选设备 + 通道 + 算法（同上）
2. 切换「监控模式」：
   - **📷 静态视图**：全量数据 + 异常标记 + 健康分
   - **🌊 流式仿真**：模拟实时数据采集

#### 流式仿真操作

1. 选择「🌊 流式仿真」
2. 配置「仿真速率」（倍速：0.5 / 1 / 2 / 5 / 10 / 20 / 50）
3. 点击「▶️ 开始」
4. 观察：
   - 折线图实时滚动
   - 异常点闪现红色 ✗
   - 健康分实时变化
   - 进度条显示播放进度
5. 点击「⏸️ 停止」可中断

#### 静态视图操作

- 全量数据一次显示
- 可点 「🚨 生成告警事件」手动入库

---

### 步骤 4：算法评估

进入 **📈 算法评估**：

1. 侧边栏配置合成数据参数：
   - 样本数 / 基频 / 噪声 / 异常比例 / 随机种子
2. 上方显示生成的信号 + ground truth 红点
3. 选择参评算法（默认全选 5 种）
4. 点击「🏁 开始评估」

**结果**：

- 📊 评估指标表（P / R / F1 / ROC-AUC / PR-AUC，按 F1 排序）
- 📊 P/R/F1 柱状对比图
- 📈 ROC 曲线对比图（各算法叠加 + 随机基线）
- 🏆 自动标出 F1 最高算法

> **用途：** 选择算法时的依据 + 课程报告/答辩素材

---

### 步骤 5：告警管理

进入 **🚨 告警中心**：

1. **过滤**：按状态（new / ack / closed）或通道
2. **查看**：列表显示所有告警（id / channel / severity / algorithm / 时间 / 备注）
3. **导出**：点 「⬇️ 导出 CSV」下载
4. **操作单条**：
   - 选择告警 ID
   - 修改状态：new → ack（已确认）→ closed（已关闭）
   - 添加备注
   - 「💾 更新」保存
   - 「🗑️ 删除」移除

---

### 步骤 6：CRUD 数据管理

**🗄️ 数据管理** 提供 4 个标签：

#### 🏭 设备标签

- 列表显示所有设备
- 「➕ 新增设备」：填名称 + 位置
- 「✏️ 编辑/删除」：选择设备 → 改名/位置 / 级联删除

#### 📡 通道标签

- 列表显示所有通道
- 新增：选所属设备 + 填通道名 + 单位 + 采样率
- 编辑/删除同上

#### 📈 信号标签

- 选通道 → 显示总数 / 异常数 / 异常率
- 显示前 N 条数据（可调）
- **单条删除**：填 ID 删除
- **清空通道**：删除该通道全部信号

## 4. 常见问题

### Q1: 启动时提示「Email」？

首次启动 Streamlit 会要求输入邮箱（用于推送活动消息），直接回车跳过即可。或预先配置：

```bash
mkdir -p ~/.streamlit
echo '[general]
email = ""' > ~/.streamlit/credentials.toml
```

### Q2: 导入大 TDMS 卡死？

务必使用**降采样**（步长 10-20）+ **截取**（每通道 < 50 万点）。SQLite 单点逐行写入是瓶颈，全量入库千万级点会卡几分钟。

### Q3: 算法效果差？

- 工业振动信号优先用 `Isolation Forest` + 勾选「使用滑窗特征」
- 噪声大用 `MAD`
- 在「算法评估」页跑对比，找最适合的算法 + 参数

### Q4: 健康分总是 100？

- 进过批量检测后才会有异常标记
- 健康分基于异常率，无异常 → 满分

### Q5: 想清空数据库重来？

```bash
rm data/anomaly.db
```

下次启动会自动重建。

### Q6: 浏览器没自动打开？

手动访问 `http://localhost:8501`。如端口被占用，启动时改端口：

```bash
streamlit run app.py --server.port 8502
```

## 5. 测试与开发

### 5.1 跑测试

```bash
pytest
pytest --cov=core --cov=algorithms --cov-report=term      # 带覆盖率
```

当前 25 个用例，**覆盖率 85%**。

### 5.2 添加新算法

1. 在 `algorithms/` 下新建文件，继承 `BaseDetector`：

```python
from algorithms.base import BaseDetector
import numpy as np

class MyDetector(BaseDetector):
    name = "my_algo"

    def __init__(self, threshold=1.0):
        self.threshold = threshold

    def fit(self, x):
        return self

    def predict(self, x):
        return (np.abs(x) > self.threshold).astype(int)

    def score(self, x):
        return np.abs(x)

    def get_params(self):
        return {"threshold": self.threshold}
```

2. 在 `algorithms/registry.py` 注册：

```python
from algorithms.my_algo import MyDetector

REGISTRY["my_algo"] = MyDetector
ALGORITHM_LABELS["my_algo"] = "我的算法"
```

3. 重启 Streamlit，UI 中即可选用。
